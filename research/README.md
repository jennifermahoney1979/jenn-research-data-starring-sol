# Research documentation

This folder separates the public case summaries from the evidence and authorship trail.

- [`WORK_EVIDENCE.md`](WORK_EVIDENCE.md) — documents Jennifer Mahoney's human research contribution: test design, execution, evidence capture, correction, classification, and cross-model analysis.
- [`EVIDENCE_MANIFEST.md`](EVIDENCE_MANIFEST.md) — maps experiments to their supporting archived records and evidence status.
- [`case-index.md`](case-index.md) — public case ledger.
- [`references/Jenns_Research_Data_Reference_Transcripts.md`](references/Jenns_Research_Data_Reference_Transcripts.md) — public reference/evidence index.

The private working archive contains the fuller screenshots, transcripts, and source documents. Public evidence files are deliberately limited to research-relevant material so that proving the work does not require publishing unrelated personal context.
