# Public PDF evidence extracts

This folder contains public-safe PDF evidence extracts for cases in the repository.

The repository is public. Full working PDFs are not mirrored here automatically when they contain unrelated personal, household, employment, health, or third-party information. In those cases, the public case record preserves only the research-relevant sequence and labels the unredacted source as private working evidence.

## Private or restricted source handling

The following source classes stay outside the public binary folder unless a redacted/public-safe copy is prepared:

- PDFs containing unrelated personal or relationship material;
- health or nutrition records;
- behavioral/educational records about third parties or minors;
- private evaluator/workplace material;
- full copyrighted source works when the research only needs a short factual or structural citation.

Markdown receipts in `research/references/` and case summaries in `research/cases/` remain the inspectable public record when a raw binary cannot responsibly be published.

## Evidence rule

A public extract is not represented as the byte-identical original. Where exact binary identity matters, the original working artifact must be checked separately. The public extracts exist to make the supported research claim inspectable without leaking unrelated material.
